# TTX.dev

Сайт-портфолио и коммерческое предложение по разработке ПО на заказ.

**Сайт:** https://totktoxam.github.io/ttx.dev/

## Что есть на сайте

- Коммерческое предложение: услуги, процесс работы, условия оплаты.
- Прайс по формуле **База (сложность) × K (пользователи) × K (данные)** в тенге и долларах.
- Калькулятор предварительной стоимости с выгрузкой предварительного КП в PDF.
- Скачивание полного КП в PDF (кнопка «КП в PDF» в шапке).
- Форма отправки ТЗ: заявка, файл ТЗ и предварительное КП в PDF приходят в Telegram через Cloudflare Worker из папки `worker/`.
- Портфолио проектов и контакты.

## Устройство

Статический сайт без сборки: `index.html` + `assets/`.

| Файл | Назначение |
| --- | --- |
| `assets/js/config.js` | Контакты, адрес приёма заявок, лимит файла |
| `assets/js/data.js` | Тексты КП, цены, коэффициенты, проекты |
| `assets/js/app.js` | Рендер, калькулятор, тема, форма ТЗ |
| `assets/js/pdf.js` | Генерация PDF (pdfmake, грузится по требованию) |
| `worker/` | Cloudflare Worker: принимает заявки и пересылает в Telegram |
| `assets/css/style.css` | Стили, светлая и тёмная тема |

## Как поменять

- **Цены и коэффициенты** — `assets/js/data.js` (`complexity`, `users`, `data`, `extras`). Сайт и PDF пересчитываются сами.
- **Контакты** — `assets/js/config.js` → `contacts`. Пустые поля на сайте не показываются.
- **Приём заявок** — бот и воркер настраиваются один раз по инструкции в [`worker/README.md`](worker/README.md), затем адрес воркера вписывается в `formEndpoint` в `config.js`.

## Локальный запуск

```bash
python -m http.server 4173
```

Откройте http://localhost:4173.
