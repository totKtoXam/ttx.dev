# Приём заявок в Telegram

Форма на сайте отправляет заявку в этот Cloudflare Worker, а он пересылает её в Telegram: текст заявки сообщением, файл ТЗ и PDF-расчёт ответом на него. Токен бота хранится в секретах воркера и на сайт не попадает.

Всё бесплатно: на бесплатном тарифе Cloudflare 100 тысяч запросов в сутки, банковская карта не нужна.

Воркер принимает заявки только с адресов из `ALLOWED_ORIGINS` и не больше 5 в минуту с одного IP.

## Настройка, один раз

### 1. Бот

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя. BotFather пришлёт токен вида `123456:ABC...`.
2. Откройте своего нового бота и нажмите «Старт», иначе он не сможет вам писать.
3. Узнайте свой chat id: напишите боту [@userinfobot](https://t.me/userinfobot), он ответит числом `Id`.
   Если заявки должны приходить в группу, добавьте бота в группу, напишите там что-нибудь и откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`: id группы отрицательный, вида `-100...`.

### 2. Воркер

Нужен Node.js. В папке `worker`:

```bash
npx wrangler login                 # откроется браузер, войдите в Cloudflare или зарегистрируйтесь
npx wrangler secret put BOT_TOKEN  # вставьте токен бота
npx wrangler secret put CHAT_ID    # вставьте chat id
npx wrangler deploy
```

`wrangler deploy` напечатает адрес вида `https://ttx-brief.<имя>.workers.dev`.

### 3. Сайт

Впишите этот адрес в `assets/js/config.js` → `formEndpoint` и опубликуйте сайт. Отправьте тестовую заявку: она должна прийти боту.

## Если что-то поменялось

- **Сайт переехал на свой домен.** Добавьте адрес в `ALLOWED_ORIGINS` в `wrangler.toml` через запятую, например `"https://totktoxam.github.io, https://ttx.dev"`, и снова `npx wrangler deploy`.
- **Токен утёк или надо сменить.** В @BotFather `/revoke`, затем `npx wrangler secret put BOT_TOKEN` с новым токеном. Сайт трогать не нужно.
- **Заявки не приходят.** `npx wrangler tail` показывает запросы и ошибки воркера в реальном времени.
